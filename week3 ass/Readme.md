# 📊 Mini Gradebook

A streamlined, web-based management tool developed for **[Mctaba Labs](https://mctaba.com)** to simplify classroom administration. This application allows educators to efficiently assign marks, calculate grades, and determine student rankings.

## ✨ Key Features
*   **Grade Calculation:** Automatically assigns letter grades based on student marks.
*   **Class Ranking:** Dynamically determines a student's position relative to their peers.
*   **Student Reports:** Generates detailed individual reports for easy progress tracking.
*   **Responsive UI:** A clean interface designed for use on various devices.

## 🛠️ Tech Stack
*   **HTML5:** Structured layout for data entry and report display.
*   **CSS3:** Styling for clear, readable tables and academic reporting.
*   **JavaScript (ES6):** Logic for calculations, grading scales, and sorting positions.

## ⚙️ Set-up Guide

To get this project running on your local machine, follow these steps:

1.  **Clone the Repository**
    ```bash
    git clone https://github.com
    ```
2.  **Open in VS Code**
    Launch **[Visual Studio Code](https://code.visualstudio.com)** and open the cloned folder.
3.  **Launch Live Server**
    Open `index.html` and click the **"Go Live"** button in the bottom-right status bar (requires the [Live Server extension](https://marketplace.visualstudio.com)).
